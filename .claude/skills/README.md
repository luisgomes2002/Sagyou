# Skills do projeto

Cada pasta é uma skill: `.claude/skills/<nome>/SKILL.md`. No Claude Code, `/<nome>` a executa, e o Claude também a carrega sozinho quando a `description` combina com a tarefa.

O fluxo que elas automatizam e a lista completa estão em [docs/workflow.md](../../docs/workflow.md) ("Skills e agentes"). Quem usa Codex/Cursor pode ler estes arquivos como checklist.

Para criar uma: siga a regra do `docs/workflow.md` (fluxo feito duas vezes do mesmo jeito, ou o mesmo erro duas vezes). Mantenha curta, faça a `description` dizer *quando* usar (não o que faz), e liste-a em `docs/workflow.md` e `AGENTS.md` no mesmo PR.
